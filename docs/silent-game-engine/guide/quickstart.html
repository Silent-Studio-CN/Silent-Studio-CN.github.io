快速开始 · SilentGameEngine

快速开始

SilentGameEngine 是一个跨语言游戏引擎，以下是最小的启动示例。

1. 创建引擎实例

from engine import Engine

engine = Engine()
engine.init()

2. 添加一个场景

scene = engine.create_scene("Main")
scene.add_cube((0, 0, 0))

3. 启动主循环

engine.run()

也可以直接运行编辑器 SgeEditor，可视化搭建场景后导出。
