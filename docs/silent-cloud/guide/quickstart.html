快速开始

SilentCloud 是 SilentStudio 的云平台核心，下面是本地启动方式。

1. 配置数据库

CREATE DATABASE SilentStudioOfficialwebsite;

2. 安装依赖并启动

pip install -r requirements.txt
python Server.py

3. 访问

浏览器打开 http://localhost:1860，注册账号即可使用官网、服务与工作流功能。

遇到问题？前往 SilentCloud 的 GitHub 仓库查看完整文档、Issues 与最新发布。
