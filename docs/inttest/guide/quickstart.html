使用

下载后双击 exe 即可启动。主窗口默认打开「速度测试」页，左侧导航共六个模块：

  • 速度测试 — 选择下载服务器（海外 / 国内线路），点击「开始测速」自动进行下载 & 上传测试。下载 6 路 HTTP Range 并发，上传 4 路并发 POST，持续 15 秒，实时显示瞬时速率和趋势图；另有极限模式（12 路 / 8 路并发，30 秒）。
  • 实时监控 — 监控当前网络接口实时上下行速率，折线图记录过去 60 秒变化，底部显示开机以来总流量。
  • 连通性测试 — 对百度、腾讯、阿里、GitHub、谷歌进行 Ping，延迟颜色分级（绿色 <100ms、橙色 <300ms、红色 ≥300ms），支持每 5 秒自动刷新。
  • 网络信息 — 本地接口详情、公网 IPv4/IPv6、运营商 ISP、地理位置与 ASN、DNS 解析与 HTTP 连通性、IPv4/IPv6 延迟对比。
  • 设置 — 切换请求 User-Agent（Chrome / Firefox / Edge / Safari 预设）。
  • 帮助 — 内置使用帮助。
测速时请关闭其他占用带宽的应用（视频、下载等）。国内用户建议选择「腾讯云」或「浙江大学」线路，海外用户建议选择「Tele2」或「OVH」线路；多次测试取平均值结果更准确。
