快速开始

SilentSafe 是 SilentStudio 出品的安全防护软件。以下步骤让你在几分钟内跑起来。

1. 环境要求

  • Windows 10/11（64 位）
  • Python 3.10+（仅 Python 组件）
  • Rust 工具链（可选，用于原生扩展）

2. 安装依赖

pip install -r requirements.txt

3. 启动

python SilentSafe.py

启动后进入主界面，点击「立即扫描」即可开始第一次全盘威胁扫描。

4. 查看报告

扫描完成后会自动生成报告：发现的问题、隔离的文件与建议动作。所有技术细节都被折叠起来，只展示你需要知道的结果。

默认防护全部开启，无需手动配置。需要深度自定义时，在设置页可以逐项调整。
