SilentStudioWebSite

SilentStudio 的核心产品。多语言官网 + 可视化工作流编辑器 + 3D 建模流，让「工作流」不止工作，也成为创作的画布。

功能特性

多语言

中 / 英 / 日三语，自动语言识别。

工作流编辑器

节点式可视化编程，支持代码节点。

3D 建模流

三参数节点连接同一 3D 视窗，实时控制模型。

文件节点

上传 Word / PPT / Excel / 音视频 / 3D 模型，随工作流保存。
