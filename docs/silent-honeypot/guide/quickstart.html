快速开始

SilentHoneypot 由 sensor（诱饵端）与 analyzer（分析端）两部分组成。

1. 构建

cargo build --release

2. 配置 sensor

# config.json 示例
{
  "baits": ["ssh", "ftp", "http"],
  "listen": "0.0.0.0:2222"
}

3. 运行

shp-sensor.exe --config config.json
shp-analyzer.exe

4. 查看情报

攻击事件会自动入库并上报，可结合 SilentSafeDateBaseServer 汇聚成威胁情报。
