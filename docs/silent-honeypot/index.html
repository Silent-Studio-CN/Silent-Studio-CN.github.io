SilentHoneypot

用 Rust 打造的蜜罐诱捕系统。模拟 SSH / FTP / HTTP 诱饵，自动采集攻击行为，为威胁情报提供一手数据。

功能特性

多协议诱饵

内置 SSH / FTP / HTTP 诱饵服务，模仿真实服务引诱攻击者。

原生性能

Rust 编写，低资源占用，可长时间稳定运行。

攻击分析

analyzer 组件自动解析会话，提取攻击指纹。

YARA 规则

支持 YARA 规则匹配，识别恶意样本。
